# Task Configuration from JSON Statistics

This document explains how to load statistics from JSON files (generated by `calculate_std_mean.py`) and create new task configurations in `constants_dvrk.py`.

## ⚠️ IMPORTANT: Where Are Created Configs Stored?

**The configs are NOT automatically written to the `constants_dvrk.py` file permanently.**

When you use these tools, the task configuration is created in memory. To actually use it:

### **Recommended Approach:** Add the function call in your training/inference script
```python
from dvrk_scripts.constants_dvrk import add_task_config_from_json, TASK_CONFIGS

# This runs each time your script starts
add_task_config_from_json(
    'my_task',
    './std_mean_invivo.json',
    dataset_dir="/path/to/data",
    tissue_ids=[1, 2, 3],
    num_episodes=1000
)

# Now use it
config = TASK_CONFIGS['my_task']
```

### **Alternative:** Manually add to `constants_dvrk.py`
Copy the output from `quick_add_config.py` and manually add it to the `TASK_CONFIGS` dictionary in `constants_dvrk.py`.

## Overview

The enhanced `constants_dvrk.py` now includes three main utility functions:

1. **`load_statistics_from_json(json_path)`** - Load statistics from a JSON file
2. **`create_task_config_from_json(...)`** - Create a task configuration dictionary
3. **`add_task_config_from_json(...)`** - Create and add a task config to `TASK_CONFIGS`

## Quick Start

### Method 1: Using Python Code

```python
from dvrk_scripts.constants_dvrk import add_task_config_from_json, TASK_CONFIGS

# Add a new task configuration from JSON
add_task_config_from_json(
    task_name='my_invivo_task',
    json_path='./std_mean_invivo.json',
    dataset_dir="/home/iulian/chole_ws/data/cnh_exvivo_chole",
    tissue_ids=[1, 2, 3],
    tissue_ids_val=[4],
    num_episodes=1000,
    num_episodes_val=50,
    camera_names=['left', 'left_wrist', 'right_wrist']
)

# Use the configuration
config = TASK_CONFIGS['my_invivo_task']
```

### Method 2: Using Command-Line Tool

```bash
# Add a task configuration using the command-line tool
python dvrk_scripts/quick_add_config.py my_task ./std_mean_invivo.json \
    --dataset-dir /home/iulian/chole_ws/data/cnh_exvivo_chole \
    --tissue-ids 1 2 3 \
    --tissue-ids-val 4 \
    --num-episodes 1000 \
    --num-episodes-val 50

# List all existing configurations
python dvrk_scripts/quick_add_config.py --list-configs

# Show statistics from JSON file
python dvrk_scripts/quick_add_config.py --show-stats ./std_mean_invivo.json
```

## Function Reference

### `load_statistics_from_json(json_path)`

Load statistics (mean, std, min, max) from a JSON file.

**Parameters:**
- `json_path` (str): Path to JSON file containing statistics

**Returns:**
- `dict`: Dictionary with keys: `'mean'`, `'std'`, `'min'`, `'max'` (all numpy arrays)

**Example:**
```python
from dvrk_scripts.constants_dvrk import load_statistics_from_json

stats = load_statistics_from_json('./std_mean_invivo.json')
print(f"Mean: {stats['mean']}")
print(f"Std: {stats['std']}")
```

### `create_task_config_from_json(...)`

Create a task configuration dictionary from a JSON statistics file.

**Parameters:**
- `task_name` (str): Name for the task configuration
- `json_path` (str): Path to JSON file with statistics
- `dataset_dir` (str): Path to dataset directory
- `tissue_ids` (list): List of tissue sample IDs for training
- `tissue_ids_val` (list, optional): List of tissue sample IDs for validation
- `num_episodes` (int, optional): Number of training episodes
- `num_episodes_val` (int): Number of validation episodes (default: 0)
- `phantom` (bool): Whether using phantom data (default: False)
- `use_auto_label` (bool): Whether to use auto labeling (default: False)
- `goal_condition_style` (str, optional): Goal conditioning style ('map', 'mask', 'dot')
- `no_qpos` (bool): True for SRT, False for ACT (default: False)
- `camera_file_suffixes` (list, optional): List of camera file suffixes
- `episode_len` (int): Length of episodes (default: 500)
- `cutting_action_pad_size` (int): Padding size for cutting actions (default: 0)
- `recovery_ratio` (float): Recovery ratio (default: 1.0)
- `norm_scheme` (str): Normalization scheme (default: 'std')
- `save_frequency` (int): Checkpoint save frequency (default: 50)
- `camera_names` (list, optional): List of camera names
- `merging_subtasks` (bool): Whether to merge subtasks (default: False)

**Returns:**
- `dict`: Task configuration dictionary

**Example:**
```python
from dvrk_scripts.constants_dvrk import create_task_config_from_json

config = create_task_config_from_json(
    task_name='test_task',
    json_path='./std_mean_invivo.json',
    dataset_dir="/path/to/data",
    tissue_ids=[1, 2, 3],
    num_episodes=1000,
    goal_condition_style='map',
    camera_names=['left', 'left_wrist', 'right_wrist']
)

# Manually add to TASK_CONFIGS if needed
TASK_CONFIGS['test_task'] = config
```

### `add_task_config_from_json(...)`

Create a task config from JSON and automatically add it to `TASK_CONFIGS`.

**Parameters:**
Same as `create_task_config_from_json()`

**Returns:**
- `dict`: The created task configuration dictionary

**Example:**
```python
from dvrk_scripts.constants_dvrk import add_task_config_from_json, TASK_CONFIGS

add_task_config_from_json(
    task_name='my_new_task',
    json_path='./std_mean_invivo.json',
    dataset_dir="/home/iulian/chole_ws/data",
    tissue_ids=[1, 2, 3],
    num_episodes=1000
)

# Now accessible via TASK_CONFIGS
config = TASK_CONFIGS['my_new_task']
```

## Workflow

### 1. Generate Statistics JSON

First, run `calculate_std_mean.py` to generate the statistics:

```bash
cd /home/iulian/chole_ws/src/skay_jhu_private_new/src/act
python calculate_std_mean.py
```

This will create:
- `std_mean_invivo.json` (full statistics in JSON format)
- `std_mean_invivo_summary.txt` (text summary)

```python
    tissue_ids=[1, 2, 3],
    num_episodes=853

```

Option B - Using the command-line tool:
```bash
cd dvrk_scripts
python quick_add_config.py my_task ../std_mean_invivo.json \
    --dataset-dir /home/iulian/chole_ws/data/cnh_exvivo_chole \
    --tissue-ids 1 2 3 \
    --num-episodes 853
```

### 3. Use the Configuration

```python
from dvrk_scripts.constants_dvrk import TASK_CONFIGS

config = TASK_CONFIGS['my_task']
# Use config in your training/inference code
```

## JSON File Format

The JSON statistics file (generated by `calculate_std_mean.py`) has the following format:

```json
{
  "metadata": {
    "tissue_ids": [1, 2, 3],
    "data_directory": "/path/to/data",
    "computation_time_seconds": 45.67,
    "timestamp": "2026-01-24 10:30:00"
  },
  "statistics": {
    "mean": [0.001, -0.002, ...],
    "std": [0.01, 0.015, ...],
    "min": [-0.1, -0.08, ...],
    "max": [0.09, 0.093, ...]
  }
}
```

## Benefits

1. **Reproducibility**: Statistics are saved in a structured format with metadata
2. **Automation**: No need to manually copy-paste arrays into constants_dvrk.py
3. **Version Control**: JSON files can be versioned and tracked
4. **Flexibility**: Easy to create multiple task configs with different parameters but same statistics
5. **Documentation**: Metadata includes computation time and timestamp for tracking

## Troubleshooting

**Issue**: JSON file not found
- **Solution**: Make sure you've run `calculate_std_mean.py` first, or provide the correct path

**Issue**: Task name already exists
- **Solution**: Choose a different task name or use the command-line tool which will prompt for overwrite

**Issue**: Wrong array dimensions
- **Solution**: Verify the JSON file was generated with the correct data and action dimensions
